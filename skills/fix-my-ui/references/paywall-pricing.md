# Paywalls, pricing and upgrades

- **Show value before price.** A locked feature shows what is behind it (blurred preview, a count, a sample) and one sentence on why it is worth it.
- **One paywall component**, opened with the context of what was tapped, so the copy can say "Unlock this analysis" rather than a generic pitch.
- **Plans side by side** with the recommended one marked, the price per period in the user's currency, and what changes between plans in plain words.
- **Local currency and payment methods** for each market; show the final price including fees before the user commits.
- **Free trials** state the end date and the price after, and remind before charging.
- **Credits or usage limits** show the balance before an action costs anything, and the cost of the action on the button.
- **Never dead-end.** If a payment method fails, offer another route on the same screen.
- **Cancellation** is as easy to find as sign-up.
- **Platform rules**: app stores restrict linking to outside payment; keep in-app purchase flows compliant per platform.
- **Receipts and status**: the account page shows plan, renewal date, last payment and how to manage it.
- **Don't nag.** Cap how often the same upsell appears per session; never interrupt a task the user is in the middle of.
- **Measure** every step: paywall opened, plan selected, checkout started, payment succeeded, failed (with the reason), cancelled.
