# What matters most, by type of site

The checklist applies everywhere. These are the extra priorities for each kind of product. Identify the type first; many products are two at once (a landing page in front of a dashboard).

## Marketing / landing page
- First screen: what it is, who it is for, one primary call to action, a real product visual.
- One story top to bottom: problem, how it works (three steps), proof (real logos, real numbers, real quotes), pricing, FAQ, final call to action.
- Real screenshots or short loops of the product, not abstract illustrations.
- Fast first paint; the hero must not depend on heavy scripts.
- Social share image, title and description set for every page.

## SaaS / dashboard / web app
- The home screen answers "what needs my attention now?"
- Tables: sort, filter, search, bulk actions, empty and loading states, sticky headers.
- Settings grouped by task, with save feedback; dangerous settings separated.
- Keyboard shortcuts for frequent actions; command palette if there are many.
- Permissions and roles are visible: what can this user do here?

## E-commerce / booking
- Product or listing page: price, availability, delivery or date, and the add button above the fold.
- Real photos at consistent ratios, zoom on tap.
- Cart and checkout: guest checkout, progress steps, total including fees and tax before payment, saved addresses, local payment methods.
- Order status page and emails that match each other.
- Reviews with real names or verified markers, never invented.

## Content / blog / news / docs
- Readable measure (60 to 75 characters), generous line height, clear heading hierarchy, table of contents for long pages.
- Search that works on titles and body.
- Code blocks with copy buttons (docs); dates and authors (articles); next and previous links.
- No pop-ups before the reader has read anything.

## Portfolio / agency / personal
- The work first, big; short captions with the problem, role and result.
- One way to get in touch, visible from every page.
- Personality in type and colour is welcome; legibility still wins.

## Marketplace / community / social
- Profiles: avatar, name, a short bio, what they do here, trust markers.
- Feeds: clear ranking (latest, top, following), real empty states, moderation and report flows.
- Privacy controls the user can find and understand; private accounts stay private everywhere (lists, counts, search).
- Creating content is one obvious action; drafts are saved.

## Mobile app (native or PWA)
- Bottom tab bar with 3 to 5 destinations; the thumb zone holds the primary actions.
- Platform conventions: back gestures, share sheets, system fonts where appropriate, haptics for confirmations.
- Offline and slow-network behaviour designed.
- Push, widgets and lock-screen surfaces only for things the user chose to follow.
- App store screenshots that show real screens with one benefit each.

## Fintech / health / anything with money or risk
- Every number exact, with its source and time.
- Confirm before irreversible actions, show the result after, keep a history.
- Plain-language explanations of fees, limits and risks before the user commits.
- Never present an estimate, forecast or rating as a promise.
